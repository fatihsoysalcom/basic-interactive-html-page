# Basic Interactive HTML Page

This example demonstrates a basic interactive web page, simulating the kind of simple web application that could be generated rapidly from a text prompt using AI tools like Cursor. It features a title, a paragraph, and a button that dynamically updates the text content when clicked. The entire application is self-contained within a single HTML file.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
